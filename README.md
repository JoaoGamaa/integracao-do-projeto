# Seminário Gerenciamento da Integração do Projeto

Abra `index.html` em um navegador moderno. A apresentação funciona sem instalação e sem internet.

Controles:

- Setas, Page Up e Page Down: navegar
- O: abrir tópicos
- F: tela cheia
- Home e End: primeiro e último slide

O conteúdo foi sintetizado exclusivamente do capítulo 4 do Guia PMBOK sexta edição fornecido com o trabalho.
